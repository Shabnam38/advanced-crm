# Advanced CRM — Backend

A Customer Relationship Management (CRM) system built with pure Python + Django.

## Tech Stack
- Backend: Python, Django
- Database: SQLite
- Frontend: HTML, CSS (Tailwind) — in progress

## Features
- 6 core models: Company, Customer, Lead, Deal, Task, Interaction
- Auto lead scoring based on status
- Auto deal probability based on stage
- Data validation on Deal value and Lead contact info
- Admin panel with search and filters
- API-style views with search/filter and aggregate stats
- 13 automated tests
